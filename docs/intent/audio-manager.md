# 의도: 새 코어 오디오 매니저

확정일: 2026-11-23 (interview-me 세션)

## 결과
기존 오디오 시스템을 삭제하고, 같은 `Assets/Audio` 폴더에 작고 튼튼한 **코어 오디오 매니저**를 새로 만든다.

## 사용자
- 사운드 등록·관리: 오디오 담당(현재 1인).
- 팀원 및 적/게임 코드: 등록된 소리를 **이름으로 호출만** 한다.

## 왜 지금
- 한 적의 행동 소리(idle / hear / spot 등)가 서로 겹친다.
- room 필터를 덧붙이는 과정에서 매니저 자체가 망가졌다 (핵심과 부가 기능이 한 덩어리).
- 적 코드를 수정하면 오디오 쪽에서 컴파일 오류가 났다 (양방향 결합).
- 기능을 추가하면서 사용하지 않는 소리가 쌓여 목록이 불분명해졌다.

## 핵심 기능 (첫 버전)
1. **인스펙터 목록**: 매니저 프리팹 인스펙터의 빈 목록에서 시작. 항목 이름은 **직접 정한 이름**이며, 클립을 끌어다 놓아 등록한다.
2. **변형 재생(머신건 방지)**: 한 항목에 여러 클립 → 무작위 재생, 직전 클립 연속 회피, 피치·볼륨 무작위 폭.
3. **이름 기반 호출**: 게임 코드는 `AudioManager.Play("이름", 위치/대상)` 형태로만 호출. 오디오 모듈은 게임 코드를 참조하지 않는다.
4. **주체별 단일 재생**: 한 주체(적 하나)의 행동 소리는 동시에 하나만 재생, 새 소리가 이전 소리를 대체.
5. **믹서 연결**: 기존 AudioMixer를 볼륨 그룹으로 사용.

## 성공 기준
- Enemy1의 idle / hear / spot이 겹치지 않는다.
- 적 코드를 수정해도 오디오가 컴파일 단계에서 깨지지 않는다.
- 매니저 인스펙터만 보면 현재 사용하는 소리 전체가 보인다.
