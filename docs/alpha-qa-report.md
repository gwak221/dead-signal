# DEAD SIGNAL v0.1.0-alpha - 알파 전 종합 QA 보고서

- 대상: GitHub main `7877a54` (`v0.1.0-alpha`), 작업 브랜치 `integration-on-main-1124` (내용 동일)
- 검증 환경: Unity 6000.3.24f1 **에디터 Play Mode** (배포 EXE 는 입력 전달 불가로 일부만 확인 - 10장)
- 표기: **[실플레이]** = 실제 키 입력(F/E/Space/R/W)으로 게임 로직을 통과시킨 것, **[디버그]** = 디버그 호출/강제 상태로 확인, **[코드]** = 코드/수치 분석만, **[미검증]** = 확인 못함
- 입력 방식: 에디터에서 Input System 에 키 이벤트를 넣어 실제 `PlayerInteraction`/`FirstPersonController` 경로를 탔다. 먼 거리 이동은 텔레포트로 건너뛰었다(걷기 이동 자체는 별도로 확인).

## 2. 실제 플레이(실입력)로 검증한 항목

- 이동(W)·벽 충돌, 배터리 줍기(F), 비콘 상호작용(E), 파이프 QTE 시작/ESC 취소/재진입/해결, 아이템 상자 QTE(E -> 스킬체크 -> Space) **실패 후 재도전 가능 + 성공 시 열림**, 약장 AA 줍기(F, 줍힌 AA 오브젝트 소멸), **빈 약장(`med_cabinet_004 (1)`)은 QTE 없이 즉시 열림**, 탈출 구역 진입, 사망 후 **R 길게 누르기(1.5초)** 에서 씬이 **한 번만** 로드됨.

## 3. 디버그 기능으로 검증한 항목

- 첫 번째 포획 `PlayerCaughtSequence.TriggerCaught()`: 연출 종료 후 입력 복구(이동 가능), **팔 부상(armPenalty)** 적용, 게임오버 아님.

- 타이틀 시작(`StartGame`) 직후 오디오(드론/형광등/비콘 허밍) 정상 시작.
- 스킬체크 실패/성공 판정은 스킬체크의 내부 각도를 읽어 정확한 타이밍에 Space 를 보냈다.

## 8. 난이도 / 밸런스 분석 (수치 변경 없음, 의견만)

**실측** = 이번 세션에서 직접 측정, **코드** = 코드 상수, **추정** = 계산 기반 가정

### 맵 / 시간
- 실측: NavMesh 범위 131 x 84 m. 비콘 4(+튜토리얼 1) 순회 + 탈출까지 NavMesh 경로 합계 **최소 약 520 m**(일부 구간은 가구 위 아이템이라 `PathPartial` -> 실제는 더 김).
- 코드: 걷기 5 m/s, 달리기 9 m/s. 이동만으로는 **약 2~3분**.
- 추정: QTE, 탐색, 숨기, 몬스터 회피를 포함하면 **초심자 15~30분, 숙련자 8~15분** (실제 플레이 필요 -> 알파테스트 확인).

### 아이템 / 자원
- 비콘 배터리 5개 = 필요 5개(튜토리얼 1 + 본편 4) -> **여유 0**. 5개 모두 맵에 고정, 수납장 밖 (예: 침대 위, 바닥). 팀원 맵 원본이라 변경하지 않음. 하나라도 접근 불가면 클리어 불가(이번 검증에서 5개 모두 줍기 성공).
- 손전등: 코드 - 켜 두면 1.5초당 1% (100% = 150초), AA 14개 = 연속 약 35분분 + 몬스터 스턴 1회당 35% 소모. 일반 플레이 시간 대비 **공급이 충분한 편**으로 추정(체감은 확인 필요).
- 구급상자 4개(고정 2 + 랜덤 2): 한 번 부상 + 한 번 더 잡히면 게임오버 구조라 구급상자는 사실상 "추가 목숨" 4개 -> 알파 기준 보수적이지 않을 수 있음(체감 확인).
- 주사기 5개: 효과 = 약 15초간 **심박수에 의한 달리기 제한만** 해제. BPM 상승/탐지는 그대로. 달리기 제한을 풀어도 BPM 이 계속 올라 탐지 범위가 커지므로(최대 2.4배) **활용 가치가 낮을 수 있음** -> 알파테스트 확인.
- 랜덤 아이템 탐색량: 후보 58개 지점에 AA 13 + 구급 2 + 주사기 2 = 17개, 구역당 2개 이하. 가구를 하나씩 여는 탐색(+QTE)이 필요 -> 몬스터가 순찰하는 상황에서 QTE 실패 시 심박 +38(실측 BPM 70 -> 105)이므로 위험 비용이 있다.

### 심박 / 달리기
- 코드: 휴식 70, 달리기 시 +6 BPM/초(최대 160까지 약 15초), 회복 -4 BPM/초(160 -> 70 약 22초). 160 BPM 에서 달리기 잠금, 120 이하에서 해제(약 10초). 탐지 배율은 70 -> 1.0배, 160 -> 2.4배.
- 해석: 달리기는 약 15초 연속 가능 + 약 10초 잠금. 탐지 거리가 달릴수록 커지므로 "달리면 발각 위험"이 명확한 구조.
