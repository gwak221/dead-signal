[적용 방법 - 둘 중 편한 방식 사용 (씬/.unity 수정 없음)]
1) Unity 에디터 방식:
   DeadSignal_MonsterAndBloodUpdate.unitypackage 를
   Unity 메뉴 Assets -> Import Package -> Custom Package... 로 임포트 (모든 항목 체크 후 Import)
2) 폴더 덮어쓰기 방식:
   DeadSignal_MonsterAndBloodUpdate.zip 을 팀원 프로젝트 루트(Assets 폴더가 있는 최상위 폴더)에 압축 해제해 덮어쓰기
