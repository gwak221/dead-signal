2. 기획
한 줄 목표 — 플레이어에게 공포상황에서 아슬아슬하게 줄타기 하는 경험을 준다
보기) 아슬아슬하게 살아남았다 · 내가 점점 강해진다 · 숨겨진 것을 찾아냈다 · 친구를 골탕
먹였다 · 손이 기억할 때까지 반복했다
핵심 규칙
①: 심박수를 정상 범위에 유지한다.
②: 심박수를 관리하지 못하면 패닉 상태에 빠진다.
③: 심박수에 따라 게임의 조작 난이도가 변화한다.
보기) 체력은 3칸이고 회복은 한 판에 한 번만 · 적을 처치하면 남은 시간이 5초 늘어난다 · 아
이템은 두 개까지만 들 수 있다 · 소리를 내면 적이 그쪽으로 온다
핵심 루프 — 탈출구를 찾는다 → 적에게서 도망간다 → 적의 추격 범위에서 벗어난다(박스에 숨
거나 경로 방해로 범위에서 벗어난다) → 탈출하기 위한 장치를 찾는다
보기) 숨는다 → 적 위치를 본다 → 달려가 상자를 연다 → 다시 숨는다
보기) 블록을 쌓는다 → 줄이 찬다 → 터진다 → 속도가 빨라진다
참고 게임 3개 — 무엇을 참고하는지까지 적기
① 게임명: 데드 바이 데이라이트 참고할 점: QTE요소, 핵심 규칙
② 게임명: 신요와마리 참고할 점: 심장수 사운드 및 UI
③ 게임명: 아이작의 번제 참고할 점: 방 단위로 연결되는 맵 구성
보기) 참고할 점 = 조작감 · 화면 구성 · 난이도가 올라가는 방식 · 색감 · 효과음 타이밍
